**Diagnostic build. Install this if v0.1.4 did nothing on your Mac — it will now say why.**

### What was reported

Lidwing sitting in the menu bar, the Mac still sleeping on lid close, and a message about
something else holding the machine. On inspection: protection had never been armed, there was no
Lidwing process and no watchdog running, no crash report — and **no log output at all** for
45 minutes. Nothing on the machine could say whether the app had run, refused, or died.

### What is fixed

**It says what it is doing.** Every state change is now logged. The automatic turn-on at launch —
which is the main path since v0.1.2 — logged nothing whatsoever about being attempted, so a
silent failure left no trace. To read it:

```
log show --predicate 'subsystem == "ai.flymy.lidwing"' --last 1h --info
```

**It says whether its watchdog installed.** Lidwing refuses to keep your Mac awake unless a
separate watchdog process is running, because that watchdog is what puts your sleep settings back
if the app dies. That install step reported nothing at all, so a missing watchdog and a failed
watchdog install looked identical. It now records which method worked, or why none did.

**One line was simply wrong.** With Internet Sharing running, the menu said *"…is holding this Mac
awake, so it will not sleep for now"* — and the Mac then slept the moment the lid closed. Nothing
of that kind can stop a lid-close sleep; that is the whole reason Lidwing exists. It now says the
other app is keeping the Mac from idling, which is true.

### If it still does not work

Send the output of the `log show` command above. That is what this build is for.

Also worth checking, and now visible in the log: Lidwing must live in **/Applications** and be
dragged there in **Finder**, not moved with `mv`. Run from elsewhere, or still quarantined, macOS
gives it a temporary read-only location, the watchdog cannot be installed, and Lidwing will refuse
to arm rather than protect you with no way to undo it.

### Unchanged

Mechanism proven on **one** Mac for **twelve seconds**, with a positive control. No 8-hour soak.
Nothing on Intel, Air, fanless, T2, or any macOS other than 15.5. **310 tests on Linux, 315 on
macOS 15 and macOS 26**, zero failures, zero skipped. Ad-hoc signed, so macOS refuses it once.
