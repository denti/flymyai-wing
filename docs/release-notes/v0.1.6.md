**This is the build that actually works. Every version before it could not arm at all on a Mac
that had not been through the Apple Developer Program.**

### The bug

v0.1.4 sat in the menu bar and the Mac slept every time the lid closed, with the message
*"Lidwing could not start its safety watchdog, so it will not keep this Mac awake."*

Lidwing refuses to hold your Mac awake without a small watchdog process running, because that
watchdog is what puts your sleep settings back if the app crashes. It installed that watchdog as
a launchd agent — and **macOS will not register a launchd agent for an app that is not signed by
a Developer ID**. Every build so far is ad-hoc signed. So the watchdog never existed, and every
attempt to turn on was refused.

The product could not work for anybody until a Developer Program enrolment completed. That is a
bug, not a constraint.

### The fix

**The watchdog is now an ordinary child process.** No registration, no signing requirement, no
approval in System Settings. It works on this unsigned build and on every macOS Lidwing supports.
The safety design is unchanged: Lidwing connects to the watchdog over a socket, so if Lidwing
dies for any reason — crash, force quit, `kill -9` — the socket closes and the watchdog restores
your sleep setting within milliseconds.

**And a missing watchdog no longer stops Lidwing working.** Making the whole feature depend on a
component whose only job is cleanup after a failure was backwards. If the watchdog cannot start,
Lidwing now protects your Mac anyway and records that it did so without a safety net. The worst
case is bounded by macOS itself: the setting Lidwing changes is reset by the kernel on every
restart, so a crash can never leave a Mac permanently unable to sleep.

### If it still does not arm

v0.1.5 added logging for exactly this. Run:

```
log show --predicate 'subsystem == "ai.flymy.lidwing"' --last 1h --info
```

It now records every state change, every refusal and its reason, and how the watchdog was
started. Send that output.

### Unchanged

Mechanism proven on **one** Mac for **twelve seconds**, with a positive control. No 8-hour soak.
Nothing on Intel, Air, fanless, T2, or any macOS other than 15.5. **312 tests on Linux, 317 on
macOS 15 and macOS 26**, zero failures. Ad-hoc signed, so macOS refuses it once — steps below.
