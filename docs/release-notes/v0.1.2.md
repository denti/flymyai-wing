**Install it, launch it, and it is already protecting. That is the whole flow.**

### Zero steps between installing and being protected

Drag to Applications, launch, and Lidwing is on. No wizard, no questionnaire, no permission
request, nothing to read first. This is only possible because Lidwing needs no privileges at all
— no admin password, no helper, no system setting that survives a reboot. That was the point of
the architecture, and this is where it pays out.

You can turn it off in Settings if you would rather arm it yourself.

### It tells you when something else is in control

If another app is holding your Mac awake — a `caffeinate` process, Amphetamine, KeepingYouAwake,
Lungo, or a leftover setting from a tool that crashed — Lidwing stands down rather than fighting
for a global setting, and **says so**, immediately, in the menu, naming the other holder.

That state now has its own menu-bar glyph: an outline wing with an attention dot. The grammar
across the whole set is two independent cues — **fill** means Lidwing is protecting, a **dot**
means something wants your attention. Nothing depends on colour.

This is the common case, not an edge case. If you have ever run `caffeinate`, you will see it.

### Everything that stops it is still there

Arming itself does not mean arming regardless. It still refuses, quietly and visibly, when the
battery is below your floor, when the Mac is too hot, when another app already holds it, when
there is an external display on power, and when it cannot start its own watchdog. The battery
floor, the thermal guard and the maximum-duration lease are not optional — they are what makes
turning itself on defensible.

It also waits until it knows this Mac has a lid. A desktop at launch looks exactly like a laptop
whose lid driver has not reported yet, and holding a Mac mini awake for a feature it cannot use
would be a poor first impression.

### Still true, and still the important part

The mechanism is proven on **one** Mac for **twelve seconds**, with a positive control. No 8-hour

is running on hardware nobody has tested it on — that line in the menu is not decoration.
